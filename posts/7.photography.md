### MVP and extras

The previous image showed the MVP, this was extremely important to no get side tracked.  Some extra features were drawn out in the event of spare time. These included things like:
* post status on the feed page: encourages users to return for updates
* pinned top reoccuring comment grouped together: more efficient review of feedback
* pen tool to highlight exact area for annotation

![extra features and functions](https://github.com/yviat/Blogger2017/blob/main/img/extras_ideation.jpeg?raw=true) 

### Trade-off under time constraints. Simple.

Main feature:Instead of tagging feedback using x and y coordinates I use simple bounding boxes.

While it is not specific enough for users to infer from, it prevents crowding of multiple comment section groupings and most importantly a time constraint as a one-person team.
